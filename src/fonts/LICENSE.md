(https://openfontlicense.org) and were taken from the Fontsource packages.

| Font | Designer | Use |
| --- | --- | --- |
| Anton | Vernon Adams | Display headlines |
| Instrument Serif (Italic) | Instrument | Editorial accents |
| Archivo | Omnibus-Type | Body text |
| IBM Plex Mono | IBM / Mike Abbink, Bold Monday | Labels & metadata |

`.woff2` files are used by the site; `.woff` files are used by the
server-side Open Graph image renderer, which doesn't support WOFF2.
